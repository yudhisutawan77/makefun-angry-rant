## The entry

> The seatbelt sign dings and a man four rows back launches himself up the aisle like the plane owes him money. We are parked at a gate that isn't even ready. He stands there, hunched, glaring at the overhead bin as if staring at it will make the door open faster. He will stand like that for nine minutes. He does this on every flight. He has never once beaten the jet bridge.

375 characters — inside the 400-character cap.

## How it works

`main.py` writes the rant to `$ENTRY_OUT` (a file path, or a directory
holding `entry.txt`), defaulting to `/output/entry.txt`:

```sh
ENTRY_OUT=/output python3 main.py
```
